# Content Rules

These rules govern how source material is interpreted, cleaned, reorganized, and presented.

## 1. Source hierarchy

Treat source material according to evidence strength:

1. User-provided primary files
2. User-provided supporting files
3. Explicitly approved research sources
4. General background knowledge only when the task allows it

When the user limits the task to supplied files, do not add external facts.

## 2. Never invent

Do not invent:

- URLs
- Citations
- Quotations
- Timestamps
- Statistics
- Product claims
- Customer outcomes
- Speaker names
- Company details
- Missing table values
- References allegedly mentioned in a source

If something appears incomplete, preserve uncertainty or mark it `Need Manual Check`.

## 3. Transcript cleanup

Allowed light cleanup:

- Remove filler words when they add no meaning
- Repair obvious punctuation
- Split long spoken passages into readable paragraphs
- Correct obvious transcription fragments when context is unambiguous
- Normalize repeated false starts

Do not:

- Change the speaker's position
- Add sophistication or claims the speaker did not express
- Turn casual speech into a formal essay unless requested
- Collapse distinct ideas into one if that changes chronology

## 4. Summaries

A summary must be traceable to the source.

Good summaries:
- Compress repetition
- Preserve uncertainty
- Preserve cause/effect carefully
- Preserve distinctions between fact, opinion, recommendation, and example

Bad summaries:
- Add new conclusions
- Remove important caveats
- Turn speculation into fact

## 5. Visual matching

For slides, screenshots, or frames:

- Match by topic and chronology
- Prefer the most informative image, not merely the most attractive
- Avoid duplicate visuals unless repetition is meaningful
- Keep screenshots readable
- Add captions when provenance or explanation improves understanding

## 6. Source conversion

When converting PDF, PowerPoint, Word, or Markdown:

- Preserve meaning, hierarchy, major tables, and important visuals
- Improve poor page layout when useful
- Do not preserve artificial page breaks unless they carry meaning
- Reconstruct heading hierarchy semantically
- Preserve important emphasis, warnings, definitions, and notes

## 7. Links and references

- Preserve working links supplied in source files
- Use descriptive anchor text
- Do not invent missing destination URLs from names alone
- If a source mentions a tool or website without a URL, name it without fabricating a link

## 8. Tables

- Preserve row/column meaning
- Do not silently reorder values
- Keep units with values
- Preserve notes and qualifications
- Convert tables to responsive stacked layouts only if meaning remains clear

## 9. Translation

When translation is requested:

- Preserve proper nouns, units, numbers, and technical terms accurately
- Keep source language terms when they are standard industry expressions and useful to the reader
- Do not merge translation with factual enhancement unless requested

## 10. Sensitive or private material

If source files contain unnecessary personal or confidential details:

- Do not amplify them in prominent design elements
- Follow the user's scope and omission instructions
- Preserve only what is needed for the requested output

## 11. Completeness check

Before delivery, compare the final page with the source inventory and verify:

- Every major section is represented or intentionally omitted
- Important visuals are included or intentionally excluded
- Links are preserved where available
- No major transcript segment vanished accidentally
- No table meaning changed
- No unsupported claim was introduced
