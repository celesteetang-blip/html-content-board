# Components

Use components because the information needs them, not because a page needs more visual variety.

## Summary Strip

Use for 2–5 high-level takeaways near the top of a page.

Avoid when the source does not support concise takeaways.

## Chapter Header

Use for major content transitions.

May include:
- Chapter number
- Section title
- One-sentence context
- Optional timestamp range

## Media + Text Pair

Use when a screenshot, slide, chart, or photo directly supports nearby text.

Rules:
- Image must remain inspectable
- Collapse to one column on mobile
- Keep caption close to image
- Do not force this pattern on every section

## Transcript Segment

Use for lightly cleaned transcript blocks.

May include:
- Timestamp
- Speaker label when known
- Related visual
- Key quote
- Mentioned links/tools

Do not turn every paragraph into a separate card.

## Step Sequence

Use for tutorials and SOPs.

Each major step may include:
- Step number
- Action
- Why it matters
- Screenshot
- Warning
- Success check

## Callout

Use for:
- Key insight
- Warning
- Important distinction
- Need Manual Check
- Definition

Keep callouts visually distinct but not louder than the main content unless truly critical.

## Quote Block

Use only for real quotations from the source.

Never generate a quotation from a paraphrase.

## Comparison Table

Use when readers need side-by-side evaluation.

On mobile:
- Allow controlled horizontal scroll, or
- Convert to stacked records only if comparison meaning remains clear

## Timeline

Use for chronological processes, event sequences, or milestones.

Avoid timeline styling for non-chronological lists.

## Source Links

Use for references actually supplied or verified.

Include:
- Descriptive title
- Optional source type
- Optional short context

Never fabricate URLs.

## Expandable Detail

Use native `<details>` when secondary content is useful but would interrupt the main reading flow.

Good candidates:
- Long source notes
- Secondary transcript detail
- Technical appendix material
- Supporting definitions

Do not hide core actions or essential evidence by default.

## Evidence Panel

Use in research/reference pages for:
- Data point
- Source
- Context
- Caveat

Keep evidence and interpretation clearly distinguishable.

## Code / Prompt Block

Use for copyable commands, prompts, snippets, or templates.

Preserve whitespace. Add a copy button when useful.

## Gallery

Use only when multiple visuals are genuinely related and independently useful.

Avoid tiny thumbnail grids for critical screenshots.
